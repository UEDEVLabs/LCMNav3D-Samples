# LCM Nav3D Samples

The demo levels for [LCM Nav3D](https://www.fab.com/listings/92f05e42-d7be-4de3-abe8-7b0a3e70ba73), true volumetric 3D
navigation for Unreal Engine 5.2 - 5.8: more than sixty levels with drones, birds, fish, ships, a space dogfight and
Mass crowds, and all their art.

## Install

From inside the Unreal Editor, in a project that uses LCM Nav3D: **LCM Nav3D menu > Demo Levels > Download and
Install**. The editor downloads the latest release here, checks every file, installs it into the project's
`Plugins/LCMNav3DSamples` folder and asks for a restart. Updates and removal are in the same window.

The release files are encrypted and install only through LCM Nav3D; downloading them by hand gives nothing usable.
